## 1. 安装

### 1. windows

直接通过安装包安装

下载地址：https://github.com/tporadowski/redis/releases

### 2. Mac OS

通过Homebrew工具安装

``` bash
brew install redis
```

### 3. 查看版本

``` bash
# 检查 Redis 版本
redis-server --version

# 连接到 Redis 服务器
redis-cli

# 在 redis-cli 中输入 ping 命令，若返回 PONG 则表示服务正常
127.0.0.1:6379> ping
PONG

# Ctrl + C 退出终端
```



## 2. 基本操作

### 1. 选择数据

Redis一共有16个数据库，序号从0到15

``` bash
select 序号;
```



### 2. 操作字符串类型

1. 存储单个数据

   ``` bash
   set key value
   ```

2. 存储一组数据

   ``` bash
   mset key1 value1 key2 value2 key3 value3 ...
   ```

3. 获取key对应的value

   ``` bash
   get key
   ```

4. 存储数据并设置过期时间

   因为Redis是采用内存的方式存储数据，内存空间比较是有限的

   ``` bash
   set key value ex 500  # 过期时间为500秒
   set key value px 500  # 过期时间为500毫秒
   expire b3 500         # 单独给b3设置500秒的过期时间
   ttl key               # 显示指定key的过期时间(单位秒)
   pttl key              # 显示指定key的过期时间(单位毫秒)
   persist key           # 将指定key的过期时间设置为永久
   ```

5. 删除指定的数据

   ``` bash
   del key                     # 删除单个数据
   del key1 key2 key3 ...      # 删除一组数据
   ```

6. 查看当前数据库中所有的key

   ``` bash
   keys *
   ```

7. 检查指定的key是否存在

   ``` bash
   exists key
   ```

8. 从当前数据库中随机返回一个key

   ``` bash
   randomkey
   ```

9. 将当前数据库中的数据移动到其他数据库

   ``` bash
   move key 数据库序号
   ```

10. 修改key的名称

    ```` bash
    rename 原始key 新key   # 如果新key本来就存在，会替换
    renamex 原始key 新key  # 如果新key本来就存在，会发生错误
    ````

11. 检查值的类型

    ``` bash
    type key
    ```

> 注意：key命名规范是对象名:属性名
>
> 因为Redis不像传统的数据库采用表格的方式存储数据，它是采用键值对的方式，键的命名是很容易重复的
>
> 所以要采用对象名:属性名的方式
>
> 比如：set user:info:S1001:name Jack



### 3. 操作Hash类型

无论是操作字符串类型，还是操作Hash类型，对于Redis来说都实Map类型，键值对数据。

字符串类型就相当于：Map<String,String> map = new HashMap();

而Hash类型就相当于：Map<String,Map<String,String>> map = new HashMap();

1. 存储数据

   ``` bash
   hset key 属性1 值1 属性2 值2 属性3 值3 ...
   ```

2. 获取数据

   ``` bash
   hget key 属性1      # 获取key对应的属性1的值
   hget key 属性2
   hget key 属性3
   hgetall key         # 获取所以属性名和属性值
   ```

3. 检查key是否存在

   ``` bash
   hexists key 属性      # 检查指定的key的指定属性是否存在
   exists key            # 依然是检查指定的Hash类型的key是否存在
   ```

4. 删除Hash中的某个属性

   ``` bash
   hdel key 属性    # 删除某个属性
   del key         # 删除整个key
   ```

5. 查看有多少对属性

   ``` bash
   hlen key
   ```

6. 返回全部的属性值

   ``` bash
   hvals key
   ```



### 4. 操作List类型

Redis中的List类型，更像Java中的LinkedList类型。

所以List类型就相当于：`Map<String,LinkedList<String>>`

1. 向列表头部添加元素

   ``` bash
   lpush key 元素1 元素2 元素3 ...    # 这里的元素3会添加到最前面
   ```

2. 向列表尾部添加元素

   ``` bash
   rpush key 元素1 元素2 元素3 ...    # 这里的元素3会添加到最后面
   ```

3. 在指定的元素前后插入元素

   ``` bash
   linsert key before/after 指定的元素 插入的元素
   ```

4. 查看指定列表的全部元素

   ``` bash
   lrange key 0 -1   # 获取全部元素，0是开头索引，-1是结尾索引，-2就表示倒数第二个
   lrange key 2 5    # 获取索引从2到5的元素
   ```

5. 获取元素

   ``` bash
   lindex key 元素下标
   ```

6. 删除头部元素

   ``` bash
   lpop key
   ```

7. 删除尾部元素

   ``` bash
   rpop key
   ```



### 5. 操作Set和SortedSet类型

set类型跟Java中的HashSet类型是一样的不能存储重复的数据，而HashSet其实地址使用的就是HashMap，只不过它的value值是固定的，我们只使用key来存储数据，因为要key是不允许重复的。

1. 添加一个多多个元素

   ``` bash
   sadd key 值1 值2 值3 ...
   ```

2. 查看指定set中有多少个值

   ``` bash
   scard key
   ```

3. 判断是否包含指定值

   ``` bash
   sismember key 值
   ```

4. 列出所有的值

   ``` bash
   smembers key
   ```

5. 集合的运算

   ``` bash
   # 集合之间的差集运算
   sdiff key1 key2    # 这里返回的是key1有的而key2没有的
   # 集合之间的交集运算
   sinter key1 key2   # 这里返回的是key1和key2都拥有的元素
   # 集合之间的并集运算
   sunion key1 key2   # 这里返回的是key1和key2合并后去重的总元素
   # 保存差集结果
   sdiffstore 目标集合key key1 key2 
   # 保存交集结果
   sinterstore 目标集合key key1 key2
   # 保存并集结果
   sunionstore 目标集合key key1 key2
   ```

6. 移动集合间的元素

   ``` bash
   smove 指定的key 目标key 指定的元素  # 将指定的key中的指定的元素移动到目标key集合中
   ```

7. 移除元素

   ``` bash
   # 随机移除一个
   spop key    
   # 根据指的值移除
   srem key 值
   ```

8. 添加可以排序的Set集合元素

   sadd：添加普通Set

   Zdd：添加可排序Set

   ``` bash
   # 添加元素
   zdd key 排序值1 值1 排序值2 值2 排序值3 值3    # 就是利用排序值对值进行排序
   # 移除元素
   zrem key 值      #移除时不需要指定排序值
   ```

9. 查看排序Set集合

   ``` bash
   zrange key 起始索引 截止索引   # -1 表示最后一位
   zrange key 0 -1              # 查询全部元素
   ```
