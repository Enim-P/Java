包含package.json文件的文件夹被称为一个nodejs的包
生成package.json文件的命令：
npm init       一步一步定义包描述信息 
npm init -y    包的描述信息全部采用默认值设置(就是一路回车，全使用默认值)

npm：nodejs package mamanger，它是nodejs的包管理工具
使用npm工具安装第三方包的前提是你本身要是nodejs的包
所以第三方包都会保存在node_modules文件夹中

npm install 包名 --save        安装指定的包并添加到生产环境依赖
npm install 包名 --save-dev    安装指定的包并添加到开发环境依赖
npm install 全局工具 --global   在nodejs的全局环境中安装插件
比如：npm install nodemon --global  在全局环境安装一个nodemon插件
npm update 包名                 更新包，重复运行install命令替换回去的包也是更新

生产依赖和开发依赖的区别：
生产依赖参与项目打包，开发依赖只是项目开发时需要的第三方包，不参与项目打包
以生产环境安装的依赖会记录在package.json文件的dependencies配置中
以开发环境安装的依赖会记录在package.json文件的devDependencies配置中
package-lock.json文件中会记录下载的每个包的详情
npm install                 根据package.json里面配置的依赖信息，将所有依赖重新安装回来
所以package.json文件是一定不能删除的
package-lock.json文件是可以删除的，如果有该文件，直接根据该文件的地址去下载依赖，省去了查找的过程
未来确保每次下载的依赖都是最新的，最后把package-lock.json文件后再安装依赖，因为它里面记录的可以是之前老版本

npm remove 包名              移除已安装的包
i是install的简写
r是remove的简写
-S是--save的简写（默认都是以生产环境方式安装）
-D是--save-dev的简写
-g是--global的简写

注意：可以一次性安装多个包
npm i 包1 包2 包3
注意：默认安装的是最新的包，有时需要安装指定版本的包
npm i 包@2.3

npm config get registry     查看npm配置的镜像地址
npm config set registry https://registry.npmmirror.com/   将npm的镜像地址改成国内淘宝的地址

npm是官方推出的nodejs包管理工具，已经非常好用了，性能也比较稳定
还有其他的包管理工具，常用的有两个：yarn pnpm，淘宝推出一个cnpm（不太行）
npm i yarn -g 
npm i pnpm -g

pnpm的用法跟npm一模一样
pnpm使用pnpm-lock.yaml文件记录下载包的详情信息

yarn
yarn add 包名        安装指定的包到生产环境 等同于 npm install 包名 --save
yarn add 包名 --dev  安装指定的包到开发环境 等同于 npm install 包名 --save-dev
yarn remove 包名     移除指定的包 等同于 npm remove 包名
yarn upgrade 包名    更新包 等同于 npm update 包名
yarn global add 插件    安装全局插件 等同于 npm install 插件 --global
yarn使用yarn.lock文件记录下载包的详情信息
